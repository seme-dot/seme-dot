### 🔥 Recent Work

#### Project 7 – Authentication & Password Security
Completed a full hands-on lab covering:
- Generating and analyzing password hashes (SHA-256)
- Building a simple hash maker and password cracking demonstration
- Understanding why systems store hashes instead of plaintext
- Demonstrating how weak/common passwords are cracked in seconds
- Exploring the defensive value of MFA and strong password policies

Key takeaways from the lab:
- Weak passwords (e.g. `password123`) can be cracked almost instantly with common wordlists
- Hashing + proper salting + MFA dramatically raises the cost of credential attacks
- Real-world breaches (LinkedIn, Adobe, Yahoo, etc.) often succeed because of reusable weak credentials
